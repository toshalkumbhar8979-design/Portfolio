## Project Overview

Designed a synthesisable RV32I 3-stage pipeline (Fetch/Decode/Execute) for Artix-7 FPGA.

### Technical Specifications

*   **Timing Closure:** Achieved WNS 14.42 ns and WHS 0.168 ns.
*   **Power Profile:** 0.076 W via Vivado Power Analyzer.
*   **Hardware Debugging:** Built a 16-bit register-to-LED ALU debug mapping for hardware-level validation.
*   **Optimization:** Resolved logic pruning and LUT resource drop-off (21 → 300+) using `DONT_TOUCH` constraints.

### Tools Used

*   **HDL:** Verilog HDL
*   **Platform:** Xilinx Vivado, Artix-7 FPGA (Basys 3)
