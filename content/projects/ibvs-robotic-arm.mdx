## Project Overview

Co-authored a research paper on an autonomous robotic arm sorting system selected for publication on IEEE Xplore, developed from February 2026 to June 2026.

### Contributions

* Designed an autonomous sorting system using Image-Based Visual Servoing (IBVS) on a Raspberry Pi 5, achieving 15-20 FPS real-time object tracking with under 150 ms processing latency per frame.
* Developed a camera-driven closed-loop feedback control system for real-time positioning without requiring inverse kinematics.
* Interfaced an Arduino with servo motors for robotic manipulation and pick-and-place operations, demonstrating sensor-actuator integration.
