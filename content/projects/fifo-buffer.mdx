## Project Overview

Engineered a 16-deep FSM-controlled FIFO memory module in Verilog HDL on Basys 3 with a hardware 7-segment display controller for real-time data-flow monitoring.

### Technical Details

*   **FSM Control:** Managed data flow and display states using a robust Finite State Machine.
*   **Hardware Interface:** Designed a 7-segment display controller to visualize buffer status and data.
*   **Robust Testing:** Designed and executed manual hardware test cases; debugged signal timing issues and implemented signal debouncing.
*   **Applicability:** Structured testing approach applicable to ROS 2 node validation and rqt/RViz log analysis.

### Hardware & Tools

*   **FPGA:** Artix-7 (Basys 3)
*   **HDL:** Verilog HDL
*   **Software:** Xilinx Vivado
