## Project Overview

Implemented a 128-tap LMS adaptive filter (µ = 0.01) achieving 4.14 dB SNR improvement, reducing interference power from 0.000693 to 0.000267.

### Key Performance

*   **SNR Improvement:** 4.14 dB.
*   **Interference Reduction:** Significant reduction in interference power metrics.
*   **Methodology:** Signal processing methodology applicable to LiDAR/IMU noise filtering in robotic perception pipelines.

### Environment & Tools

*   **Language:** Python
*   **Algorithms:** Least Mean Squares (LMS)
*   **Libraries:** Librosa, Matplotlib, Google Colab
