## Project Overview

Academic project conducted at **Bharat Forge Aerospace** (Automation & Sensor Integration).

### Contributions

*   **Electromechanical Design:** Translated 3D CAD layouts into a fully operational electromechanical system architecture.
*   **Sensor Selection:** Selected proximity, optical, and thickness sensors/actuators against strict aerospace tolerance requirements via datasheet evaluation.
*   **I/O Mapping & Communication:** Configured hardware I/O mapping and communication protocols (CAN, I2C).
*   **HMI Development:** Programmed HMI layouts for real-time sensor visualisation, fault detection, and alarm handling.
