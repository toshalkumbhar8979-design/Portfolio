## Project Overview

Automation and Sensor Integration academic project conducted at **Bharat Forge Aerospace** in Pune, India from April 2026 to July 2026.

### Contributions

*   **Electromechanical Design:** Translated 3D CAD layouts into a fully operational electromechanical system architecture.
*   **Sensor Selection:** Selected proximity, optical, and thickness sensors/actuators against strict aerospace tolerance requirements via datasheet evaluation.
*   **I/O Mapping & Communication:** Configured hardware I/O mapping and CAN and EtherCAT communication protocols.
*   **HMI Development:** Programmed WinCC and ISPSoft/DOPSoft HMI layouts for real-time sensor visualisation, fault detection, and alarm handling.
*   **Defect Detection:** Built a two-stage pipeline using YOLO for blade-body localisation and HRNet for pixel-level scratch and surface-defect segmentation within the detected blade region.
