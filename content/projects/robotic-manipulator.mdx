## Project Overview

Architected a Master-Slave 6-DOF robotic manipulator using **Raspberry Pi 5 (master)** and **Arduino UNO (slave)** with real-time coordinate mapping and inverse kinematics for precision pick-and-place sequences.

### Key Features

*   **Integrated Image-Based Visual Servoing (IBVS):** Leveraged OpenCV for autonomous object detection and localisation, analogous to ROS 2 camera and sensor integration pipelines.
*   **Master-Slave Architecture:** Raspberry Pi 5 handles high-level vision processing and coordinate calculation, while Arduino UNO executes low-level motor control.
*   **Inverse Kinematics:** Implemented precise motion control for 6 degrees of freedom.

### Ongoing Development

Currently extending the system with a **digital twin** and **imitation learning** using BabyROS (codebase to be published on GitHub).
