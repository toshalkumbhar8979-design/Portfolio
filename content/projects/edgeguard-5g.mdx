## Project Overview

Developed a high-performance edge monitoring system for 5G Radio Access Networks using C++ and TensorFlow.

### Technical Achievements

*   **Synthetic Data Pipeline:** Engineered a pipeline to simulate 1 million rows of 5G telemetry, incorporating variables such as SNR, Power Wattage, and Hardware Temperature.
*   **Automated Self-Healing:** Built a protocol that triggers frequency shifts and power scaling based on a **95.4% accurate predictive model**, significantly reducing potential network downtime.
*   **Exploratory Data Analysis (EDA):** Identified a 0.65 correlation between power consumption spikes and antenna failure states, enabling proactive maintenance.

### Technologies Used

*   **Languages:** C++, Python
*   **Frameworks:** TensorFlow, Keras, TFLite, Scikit-learn
